# 쿠팡 밀크런 도우미 기능 스펙 (초안)

## 1. 기능명
- **쿠팡 밀크런 도우미**

## 2. 목표
- 기존 구글시트 Apps Script로 처리하던 쿠팡 파렛트 적재리스트 자동화를 FlowButler 웹 기능으로 이전한다.
- `PO`와 `SKU` 데이터를 업로드하면 센터별 적재리스트에 필요한 박스 수, 팔레트 수, PT 블록 배치를 계산한다.
- 최종적으로 센터별 PDF 다운로드까지 지원한다.

## 3. 현재 구글시트 코드 흐름 이해
1. `calculatePalletsFinal`
   - `PO` 시트와 `SKU` 시트를 읽는다.
   - SKU별 `Box 입수 수량`, `박스/파레트` 값을 기준으로 `박스 수`, `팔레트 수`, `병합Key`를 계산한다.
2. `copyPoToWorkSheetWithSkuAndNameAndColor`
   - `PO` 데이터를 `작업판` 시트에 복사한다.
   - SKU 마스터의 색상코드를 상품명 셀 배경색으로 적용한다.
3. `fetchCoupangTemplateData`
   - 센터명 기준으로 PO 행을 필터링한다.
   - 입고예정일, 발주번호, 총 박스 수, PT 수, SKU 그룹을 계산한다.
   - SKU별 물량을 팔레트 단위 chunk로 나누고 PT별 배치를 만든다.
4. `setupCoupangPalletTemplate`
   - `적재리스트 생성` 시트에 쿠팡 파렛트 적재리스트 블록을 그린다.
   - SKU별 박스 수, 수량, PT 점유율 노트를 입력한다.
5. `exportAllCentersToPDF`
   - 생성된 PT 블록을 센터별로 묶는다.
   - 임시 시트에 블록을 복사한 뒤 PDF로 내보낸다.

## 4. 입력 데이터 초안

### 4-1. PO 필수 헤더
- `입고예정일`
- `물류센터`
- `발주번호`
- `상품번호`
- `상품이름`
- `확정수량`

### 4-2. SKU 필수 헤더
- `SKU No`
- `Box 입수 수량`
- `박스/파레트`
- `Pallet 입수 수량`
- `색상코드` (작업판 색상 표시용, v1에서는 선택 가능)

## 5. 계산 규칙 초안
- `박스 수 = 확정수량 / Box 입수 수량`
- `팔레트 수 = 박스 수 / 박스/파레트`
- 센터별로 PO를 그룹화한다.
- SKU별 총 박스 수와 총 낱개 수량을 합산한다.
- 한 SKU가 팔레트 최대 적재량을 넘으면 여러 chunk로 분할한다.
- PT 배치는 점유율 1.0 초과 또는 SKU 수 제한 초과 시 다음 PT로 넘긴다.
- 기존 로직 기준으로 PT 점유율이 0.65 이하이면 최대 SKU 수 8개, 그 외에는 기본 4개를 사용한다.

## 6. 웹 구현 순서
1. PO/SKU 업로드 UI 추가
2. SheetJS 기반 PO/SKU 파서 작성
3. 필수 헤더 검증 및 행 단위 오류 메시지 작성
4. Apps Script 계산 로직을 순수 JavaScript 유틸로 분리
5. 센터별 PT 배치 결과 미리보기 구현
6. 적재리스트 PDF 렌더링 및 센터별 다운로드 구현
7. 구글시트 코드와 샘플 데이터 기준 회귀 테스트 작성

## 7. 초기 UI 상태
- 대시보드 도구 메뉴에 `쿠팡 밀크런 도우미` 항목을 추가한다.
- 첫 화면은 기능 이해 요약과 개발 순서를 보여주는 스캐폴딩 상태로 둔다.
- 실제 업로드/계산/다운로드 기능은 후속 단계에서 연결한다.
